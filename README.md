# Claude API Keys

Just a small project where I’m sharing Claude account access so people can try it out without paying.

## How to use

1. Download the folder from this repository.
2. Unzip it.
3. Open the folder and check the provided account details.
4. Log in to Claude using the **provided email and password**.

> **Important:** Don't use your own email address. Use the email that comes with the account.

## A few things to keep in mind

- These accounts are shared for testing purposes.
- Don't change the account details.
- Don't share or sell the credentials.
- If an account stops working, contact khushagra@tuta.io

That's pretty much it. Have fun testing Claude.
